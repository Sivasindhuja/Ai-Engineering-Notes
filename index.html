Exhaustive Python Study Guide

1. Getting Started

Python is an interpreted language. This means you write .py files and pass them to an interpreter. It can also be run directly in a browser or command line.

Installation Checks

# Windows
C:\Users\Name>python --version

# Linux / Mac
python --version

Interactive Mode

Type python or py in your terminal to enter the Python shell (>>>). Use exit() to quit.

2. Basic Syntax

Python uses indentation to indicate code blocks. While other languages use {}, Python requires whitespace.

if 5 > 2:
    print("This is correct!")
# print("Error!") <- Missing indentation will cause a SyntaxError
Best practice: Use 4 spaces for indentation. You must use the same number of spaces in the same block.

Statements

Instructions are called statements. They usually end with a newline. Semicolons are optional and rarely used to put multiple statements on one line.

3. Variables & Scope

Variables are created when a value is assigned. They do not require type declaration.

x = 10
name = "Dev"
print(type(x)) #

Naming Rules

  • Must start with a letter or underscore.
  • Cannot start with a number.
  • Only alphanumeric characters and underscores (A-z, 0-9, and _).
  • Case-sensitive (age, Age, and AGE are three different variables).

Variable Styles

Camel Case: myVariableName | Pascal Case: MyVariableName | Snake Case: my_variable_name

Multiple Values

x, y, z = "A", "B", "C" # Many to Many
x = y = z = "Same"      # One to Many
fruits = ["apple", "banana"]
x, y = fruits           # Unpacking a list

Global Keyword

Use global to create or modify a variable inside a function so it belongs to the global scope.

5. Numbers & Random

Int: Whole numbers of unlimited length.
Float: Numbers with decimals, or scientific "e" to indicate power of 10 (e.g., 12E4).
Complex: Written with a "j" (e.g., 3+5j).

import random
print(random.randrange(1, 10)) # Random number 1-9

6. Casting Constructors

  • int(): From float (removes decimals) or string literal.
  • float(): From int or string.
  • str(): From numbers or other types.

7. Strings & Slicing

Strings are arrays of Unicode characters. Python does not have a char type; a single character is a string of length 1.

a = "Hello World"
print(a[1])    # Indexing (e)
print(a[2:5])  # Slicing (llo)
print(a[:5])   # Start to index 5 (Hello)
print(a[2:])   # Index 2 to end (llo World)
print(a[-5:-2]) # Negative indexing (orl)

F-Strings (Python 3.6+)

price = 50
txt = f"The price is {price:.2f} dollars" # Modifiers allowed

Escape Characters

Use \ for: \" (Double quote), \n (Newline), \t (Tab).

9. Booleans

Evaluates to True or False.

Values that are False: None, 0, "", (), [], {}, and empty objects.

print(bool(False)) # False
print(bool(15))    # True
print(isinstance(200, int)) # Returns True

10. Operators & Precedence

Arithmetic

+ , - , * , / , % (Modulus), ** (Exponent), // (Floor division).

Logical

and (Both true), or (One true), not (Reverse result).

Identity & Membership

is (Same memory location), is not.
in (Present in sequence), not in.

Precedence (High to Low)

Parentheses () → Exponent ** → Multiply/Divide → Add/Sub → Comparisons → Logic (not, and, or).

11. Lists (Full Operations)

Ordered, changeable, and allows duplicates. Defined with [].

fruits = ["apple", "banana", "cherry"]
fruits[1:3] = ["kiwi", "mango"] # Change range
fruits.append("orange")         # Add to end
fruits.insert(1, "lemon")      # Add at index
fruits.extend(tropical_list)   # Add another collection
fruits.remove("kiwi")          # Remove specific item
fruits.pop(1)                  # Remove index 1
del fruits[0]                  # Delete index 0
fruits.clear()                 # Empties list

Sorting & Copying

mylist.sort()                # Alphanumeric ascending
mylist.sort(reverse=True)    # Descending
mylist.sort(key=str.lower)   # Case-insensitive
new_list = mylist.copy()     # Proper copy (not a reference)

List Comprehension

# newlist = [expression for item in iterable if condition]
vowels = [x for x in "education" if x in "aeiou"]

12. Tuples (Immutable)

Ordered and unchangeable. Defined with ().

Workaround: To update a tuple, convert to list → change → convert back to tuple.

colors = ("red", "green", "blue")
# single_item = ("red",) <- comma required!

Unpacking

fruits = ("apple", "banana", "cherry", "strawberry")
(green, yellow, *red) = fruits # red becomes a list of the rest

13. Sets (Unordered)

Unordered, unchangeable (but addable/removable), and no duplicates.

Duplicates: True and 1 are considered the same. False and 0 are considered the same.

myset = {"apple", "banana"}
myset.add("cherry")
myset.update(["kiwi", "orange"])
myset.remove("banana")  # Raises error if not found
myset.discard("banana") # Does NOT raise error
x = myset.pop()         # Removes a RANDOM item

Joining Sets

  • union() or |: All items from both.
  • intersection() or &: Only duplicates.
  • difference() or -: Only items in first set.
  • symmetric_difference() or ^: Items NOT in both.

14. Frozenset

An immutable version of a set. Created using frozenset(). It supports non-mutating methods like union() and intersection() but not add() or remove().

15. Dictionaries (Key:Value)

Ordered (since 3.7), changeable, and no duplicate keys.

user = {"name": "Emil", "age": 25}
print(user["name"])
print(user.get("age"))
print(user.keys())   # Returns list of keys
print(user.values()) # Returns list of values
print(user.items())  # Returns list of tuples
user.update({"age": 26})
user.pop("name")     # Remove key
user.popitem()       # Remove last inserted item

16. If, Elif, Else & Match

# Standard if-elif-else
if a > b:
    pass # placeholder
elif a == b:
    print("Equal")
else:
    print("B is bigger")

# Shorthand (Ternary)
print("A") if a > b else print("B")

Match Statement (3.10+)

match status:
    case 200 | 201:
        print("Success")
    case 404:
        print("Not Found")
    case _ if status > 500: # Case with Guard
        print("Server Error")
    case _:
        print("Default case")

17. Loops (While & For)

While Loop

Runs as long as the condition is true.

i = 1
while i < 6:
    if i == 3: break     # Exit loop
    if i == 2: continue  # Skip iteration
    print(i)
    i += 1
else:
    print("Done") # Runs if loop finished without break

For Loop

Iterates over a sequence.

for x in range(2, 30, 3): # start, stop, step
    print(x)

# Nested Loops
for x in ["red", "big"]:
    for y in ["apple", "cherry"]:
        print(x, y)
